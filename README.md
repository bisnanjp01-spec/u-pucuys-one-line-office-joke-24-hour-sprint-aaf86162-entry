## What it does

`main.ts` (Node 22, standard library only) writes one single-line joke about office life to `/output/entry.txt`.

> Our office printer only jams on deadline day, which is how I know it has a better sense of timing than my manager.

The joke is 114 characters: one line, one sentence, setup and punchline on the same line — inside the gate of 1–200 characters of UTF-8 text.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network, no environment secrets. Running it twice produces byte-identical output.
